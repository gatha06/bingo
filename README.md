> This project is a minimalist, web-based **[Bingo Game](https://github.com/gatha06/bingo)** built with a Python ([Flask](https://github.com/gatha06/bingo/blob/main/server.py)) backend and an interactive HTML/CSS/JavaScript frontend. It features dynamically generated randomized number grids, click-to-mark tile interactivity, and real-time win-condition tracking for completed rows, columns, and diagonals.
